# Сервис корпоративных объявлений

Индивидуальный проект ПР1–ПР5 продолжен в ПР6: веб-часть сервиса корпоративных
объявлений переведена на систему шаблонов Django. Предметная область,
консольное приложение, объекты `Announcement` и JSON-хранилище сохранены.

## Возможности

- главная страница с краткой лентой и количеством активных объявлений;
- отдельные страницы всех, активных и архивных объявлений;
- поиск по заголовку и отделу на JavaScript;
- отдельная страница объявления по динамическому URL;
- настраиваемая страница ошибки 404;
- наследуемые Django-шаблоны с общими включаемыми частями;
- русскоязычная адаптивная вёрстка, CSS-стили и SVG-иллюстрация;
- проектный каталог `templates/`, общая навигация и поиск без перезагрузки;
- совместное использование веб-сайтом и консольным приложением общей бизнес-
  логики и данных из `data/announcements.json`.

## Структура проекта

- `manage.py` — команды Django;
- `corporate_site/` — настройки проекта, включая путь к шаблонам, и маршрутизация;
- `portal/` — веб-приложение, обработчики страниц, URL, CSS, JavaScript и SVG;
- `templates/` — проектные шаблоны и общие включаемые части;
- `announcements.py` — модель предметной области и бизнес-правила ПР3;
- `storage.py` — загрузка и сохранение объявлений в JSON;
- `main.py` — прежняя консольная точка входа;
- `data/announcements.json` — общее хранилище объявлений;
- `tests/test_announcements.py` — тесты бизнес-логики и JSON-хранилища;
- `portal/tests.py` — тесты страниц и маршрутизации Django.

## Установка и запуск

В Windows PowerShell из каталога проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py runserver
```

Откройте http://127.0.0.1:8000/. Веб-сайт читает существующий файл JSON и не
изменяет его.

Для консольной версии по-прежнему доступна команда:

```powershell
python main.py
```

## Маршруты

| URL | Страница |
| --- | --- |
| `/` | Главная страница |
| `/announcements/` | Все объявления |
| `/announcements/active/` | Активные объявления |
| `/announcements/archive/` | Архив опубликованных объявлений |
| `/announcements/1/` | Страница объявления по динамическому номеру |

Номер в URL соответствует позиции объявления в списке, отсортированном по
приоритету. Несуществующие страницы и объявления возвращают ошибку 404. Для
продуктивного развёртывания задайте секретный ключ через `DJANGO_SECRET_KEY`,
установите `DJANGO_DEBUG=0` и укажите свои домены через
`DJANGO_ALLOWED_HOSTS`.
