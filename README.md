# Сервис корпоративных объявлений

Веб-приложение на Django для публикации и просмотра корпоративных объявлений. Хранилище предметной области переведено с JSON на SQLite; исходный JSON остаётся источником первичного импорта.

## Возможности

- главная страница с последними и активными объявлениями;
- списки всех, активных на выбранную дату и архивных объявлений;
- подробная страница объявления;
- статистика по общему количеству, публикациям, отделам и приоритетам;
- поиск по заголовку или отделу в списке на стороне браузера;
- SQLite-хранилище с внешним ключом на отдел, проверками значений и индексами.

## Структура базы данных

База данных предметной области находится в `data/announcements.sqlite3`. Схема хранится в `sql/schema.sql`, примеры запросов (включая параметризованные) — в `sql/queries.sql`.

- `departments`: `id INTEGER PRIMARY KEY`, `name TEXT NOT NULL UNIQUE`;
- `announcements`: `id INTEGER PRIMARY KEY`, `title TEXT`, `text TEXT`, `department_id INTEGER` (FK на `departments.id`), `priority INTEGER` (1–3), `publish_date TEXT`, `expiry_date TEXT`, `is_published INTEGER` (0/1). Даты хранятся в ISO-формате `YYYY-MM-DD`; схема проверяет даты, диапазон приоритета, флаг публикации и то, что окончание не раньше публикации.

`db/database.py` включает `PRAGMA foreign_keys = ON` для каждого соединения и возвращает строки `sqlite3.Row`. `db/import_json.py` заменяет набор записей атомарным повторяемым импортом. Порядок записей исходного JSON задаёт ID при импорте; отделы нормализованы в отдельную таблицу.

## Установка и запуск

В Windows PowerShell из каталога проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m db.import_json
python manage.py runserver
```

Откройте http://127.0.0.1:8000/. Для повторного импорта можно указать свои пути: `python -m db.import_json --json путь\к\данным.json --db путь\к\базе.sqlite3`. Импорт полностью заменяет таблицы `announcements` и `departments` данными JSON-файла.

Django использует отдельный `db.sqlite3` для собственных компонентов (например, сессий и авторизации); объявления хранятся в `data/announcements.sqlite3`.

## Маршруты

| URL | Страница |
| --- | --- |
| `/` | Главная |
| `/announcements/` | Все объявления |
| `/announcements/active/` | Активные объявления; параметр `?date=YYYY-MM-DD` меняет дату выборки |
| `/announcements/archive/` | Архив опубликованных объявлений |
| `/announcements/<id>/` | Страница объявления по ID SQLite |
| `/statistics/` | Сводная статистика |

Предметная область проекта — корпоративные объявления. В адаптированном чек-листе список помещений заменён списком объявлений из SQLite, список бронирований — архивом опубликованных объявлений, а поиск свободных помещений по дате — выбором активных объявлений на выбранную дату.
