# Сервис корпоративных объявлений

Консольный учебный проект ПР1/ПР2 для хранения и проверки объявлений
внутри организации.

## Возможности

- хранение объявлений в списке словарей;
- создание объявления с проверкой заголовка, отдела, приоритета и дат;
- фильтрация опубликованных и неистёкших объявлений генератором;
- сортировка по приоритету с помощью `lambda`;
- загрузка и сохранение данных в `data/announcements.json`;
- обработка ошибок ввода и ошибок файлового хранилища;
- демонстрация интроспекции сигнатуры функции через `inspect`.

## Структура

- `main.py` — точка запуска и консольный сценарий;
- `announcements.py` — структуры данных и правила предметной области;
- `storage.py` — чтение и запись JSON через контекстный менеджер;
- `utils.py` — общие утилиты и интроспекция;
- `tests/test_announcements.py` — тесты pytest;
- `data/announcements.json` — созданное приложением локальное хранилище.

## Запуск

```text
python main.py
```

При первом запуске приложение создаёт каталог `data` и сохраняет пример
объявления. При следующих запусках данные загружаются из JSON.

## Проверка

```text
python -m pytest -q
flake8
```

В проекте есть пять тестов: проверка ошибок создания, генератора активных
объявлений, сортировки, JSON round-trip и расчёта срока действия.

## Применённые возможности Python

Проект разделён на модули с документацией функций и аннотациями основных
сигнатур. Используются пространства имён модулей, коллекции, циклы,
генератор `active_announcements`, `lambda`, исключения `AnnouncementError`
и `StorageError`, контекстный менеджер `with` для файлов и модуль
интроспекции `inspect`.
