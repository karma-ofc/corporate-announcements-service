# Сервис корпоративных объявлений

## Назначение

Веб-сервис для публикации, хранения и просмотра корпоративных объявлений внутри организации. Приложение помогает сотрудникам и HR быстро доносить важную информацию (изменения регламентов, мероприятия, технические работы) до нужных подразделений и отслеживать актуальность сообщений.

## Целевая аудитория

- **Сотрудники компании** — читают объявления, фильтруют по отделу и приоритету.
- **HR и внутренние коммуникаторы** — создают и публикуют объявления.
- **Руководители подразделений** — публикуют объявления для своих команд и контролируют срок действия.

## Предметная область

Корпоративные внутренние коммуникации: объявления с заголовком, текстом, автором, целевым отделом, приоритетом, датой публикации и сроком действия. Связи между объявлениями, отделами и пользователями-авторами будут храниться в базе данных на следующих этапах разработки.

## Основные сущности

- **Объявление (Announcement)** — заголовок, текст, дата публикации, срок действия, признак опубликованности, уровень приоритета.
- **Отдел (Department)** — название и код подразделения, для которого предназначено объявление.
- **Пользователь (User)** — сотрудник, создающий или просматривающий объявления; роли (читатель, автор, администратор) планируются позже.

## Основные функции

- **Проверка статуса публикации** — определение, видно ли объявление сотрудникам (опубликовано и не снято с публикации).
- **Оценка приоритета** — отображение уровня срочности объявления (низкий, средний, высокий) для интерфейса и уведомлений.
- **Валидация заголовка** — проверка длины и непустоты заголовка перед сохранением черновика.
- **Контроль срока действия** — расчёт оставшихся дней до истечения объявления и предупреждение об истечении.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
