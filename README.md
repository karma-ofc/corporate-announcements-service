# Сервис корпоративных объявлений

Учебный консольный проект ПР3, продолжение проекта ПР2. Сервис хранит
объявления сотрудников в JSON, создает объекты предметной области и выводит
сведения об их публикации и сроке действия.

## Возможности

- создание объектов `Announcement` с проверкой заголовка, отдела, приоритета и
	дат;
- методы объекта `is_active`, `to_dict` и строковое представление `__str__`;
- загрузка JSON в объекты через декоратор `@classmethod` `from_dict`;
- сохранение объектов в прежнем JSON-формате;
- фильтрация опубликованных и неистекших объявлений генератором;
- сортировка объектов по приоритету;
- обработка ошибок ввода, JSON и файлового хранилища;
- демонстрация декораторов, `lambda`, генератора и интроспекции `inspect`.

## Классы и взаимодействие

| Класс | Атрибуты | Методы |
| --- | --- | --- |
| `Announcement` | `title`, `text`, `department`, `priority`, `publish_date`, `expiry_date`, `is_published` | `__init__`, `__str__`, `is_active`, `to_dict`, `from_dict` |
| `AnnouncementError` | сообщение ошибки | наследуется от `ValueError` |
| `StorageError` | сообщение ошибки | наследуется от `RuntimeError` |

`storage.load_announcements` читает список словарей из JSON и создает объекты
через `Announcement.from_dict`. `storage.save_announcements` вызывает
`to_dict` у каждого объекта. Функции `active_announcements` и
`sort_by_priority` работают с коллекцией объектов, а `main.run` связывает
хранилище, бизнес-правила и консольный вывод.

## Структура проекта

- `main.py` — точка запуска и консольный сценарий;
- `announcements.py` — класс предметной области и правила объявлений;
- `storage.py` — чтение и запись JSON;
- `utils.py` — утилита интроспекции сигнатур;
- `tests/test_announcements.py` — автоматизированные тесты pytest;
- `data/announcements.json` — локальное JSON-хранилище.

## Запуск

```text

```
